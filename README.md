# 빈틈없슈 · SGS 웹사이트 프로토타입

숭실대학교 교내 환경봉사 플랫폼 `빈틈없슈` 정적 웹사이트 프로토타입입니다.

## 구성 파일

- `index.html`
- `styles.css`
- `floor-certification.css`
- `script.js`
- `supabase-setup.sql`
- `README.md`

## 로컬 실행법

1. 이 폴더의 압축을 풉니다.
2. `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 별도 서버 설치 없이 실행됩니다.

## 로그인 안내

- 학생 로그인 버튼은 실제 숭실대학교 u-SAINT 포털(`https://saint.ssu.ac.kr/irj/portal`)로 이동합니다.
- 이 사이트는 정적 발표용 프로토타입이므로 u-SAINT 인증 성공 후 SGS로 자동 복귀하는 기능은 구현하지 않았습니다.
- 발표 시연용으로 `학생 데모로 입장` 버튼을 제공합니다.
- 관리자 데모 계정은 아래와 같습니다.

```text
ID: djvol123
Password: 0000
```

관리자 ID/PW는 `script.js` 프론트엔드 코드에 들어 있는 발표용 데모 값입니다. 실제 서비스 배포 시에는 반드시 서버 기반 인증, 세션, 권한 검증으로 교체해야 합니다.

## 주요 기능

- 학생/관리자 로그인 화면 분리
- 건물 목록, 검색, 분류 필터
- 정보과학관 포함
- 정보과학관 층 범위: B1층~6층
- 봉사 신청 전 분리수거 가이드 확인 및 3문항 퀴즈 통과
- 건물별 활동 신청
- 날짜 선택 및 과거 날짜 선택 방지
- 평일 18:00, 주말 14:00 자동 시작 시간 표시
- 형남공학관을 제외한 건물은 한 팀이 건물 전체 담당
- 일반 건물은 모든 층에서 활동 전/후 사진을 각각 인증
- 형남공학관은 한 팀이 3개 층 묶음을 선택하고 층별 전/후 사진 인증
- 형남공학관은 같은 날짜에도 서로 다른 층 묶음이면 별도 팀 신청 가능
- 팀 인원 1명 또는 2명 선택
- 내 활동 화면에서 신청 현황 확인
- 학생 데모의 내 활동에서 인증 완료 전 신청 취소
- 담당하는 각 층에서 활동 전 2장, 활동 후 2장 촬영 또는 파일 선택
- 활동 전: 이름표·전체 쓰레기통, 캔·플라스틱 칸 내부
- 활동 후: 이름표·전체 쓰레기통, 정리된 칸 내부
- 층별 쓰레기 포화도 기록: 일반쓰레기, 병·플라스틱, 캔
- 층별 분리수거 미준수 폐기물 기록: 음료용기, 배달용기, 기타
- 담당한 모든 층의 필수 사진 4장이 등록되어야 인증 대기 상태로 전환
- 사진과 조사 내용은 학생 화면에서 임시 작성 상태로 보관
- 모든 필수 사진 등록 후 `인증 완료하기`를 눌러야 관리자에게 인증 정보 전달
- 제출 후 학생 내 활동에 `인증 제출 완료 · 관리자 확인 대기` 표시
- 사진 등록 시각 표시
- 캠퍼스 지도형 건물 핀 UI
- 관리자 대시보드 요약 카드
- 신청 목록 필터
- 층별 전/후 사진과 현장 조사 데이터 비교
- 인증 승인, 재인증 요청 상태 변경
- 관리자 신청 상세에서 인증 완료 전 신청 취소
- Excel에서 열 수 있는 CSV 다운로드

## 데이터 저장 방식

Supabase 공용 데이터베이스를 사용해 여러 기기에서 같은 신청 현황을 공유합니다.

- `supabase-setup.sql`을 Supabase SQL Editor에서 한 번 실행해야 합니다.
- 같은 날짜·건물·담당 구역은 데이터베이스의 고유 조건으로 중복 신청이 차단됩니다.
- 일반 건물의 담당 구역은 건물 전체이며, 형남공학관은 3개 층 묶음별로 구분됩니다.
- 브라우저 `localStorage`는 화면을 빠르게 표시하기 위한 임시 사본으로만 사용합니다.
- 사진 이미지는 Supabase Storage의 `sgs-photos` 버킷에 저장됩니다.
- 사진 주소와 등록 시각이 신청 데이터에 저장되어 다른 기기의 관리자 화면에서도 확인할 수 있습니다.
- 사진 한 장의 최대 크기는 10MB이며 JPEG, PNG, WebP, HEIC, HEIF 형식을 허용합니다.
- 건물별 층 범위는 발표용 예시이며 `script.js`의 `BUILDINGS`에서 실제 운영 층으로 바꿀 수 있습니다.

### Supabase 최초 설정

1. Supabase 프로젝트에서 왼쪽 `SQL Editor`를 엽니다.
2. `New query`를 누릅니다.
3. 이 폴더의 `supabase-setup.sql` 전체 내용을 붙여넣습니다.
4. `Run`을 누릅니다.
5. 수정된 사이트 ZIP을 Netlify Drop에 다시 배포합니다.

현재 RLS 정책은 로그인 연동 전 발표용으로 익명 조회·등록·수정·삭제와 사진 업로드를 허용합니다. 사진 버킷도 URL을 아는 사람이 볼 수 있는 공개 버킷입니다. 실제 서비스에서는 학교 로그인과 관리자 역할을 확인하는 비공개 정책으로 교체해야 합니다.

## Netlify Drop 재배포

1. `index.html`, `styles.css`, `floor-certification.css`, `script.js`, `supabase-setup.sql`, `README.md`가 들어 있는 폴더를 준비합니다.
2. Netlify Drop 페이지로 이동합니다.
3. 폴더 전체를 드롭 영역에 끌어다 놓습니다.
4. 배포가 끝나면 생성된 `netlify.app` 주소로 접속합니다.

- 신청 데이터베이스 구축

- 개인정보 및 봉사 인증 정책 검토
